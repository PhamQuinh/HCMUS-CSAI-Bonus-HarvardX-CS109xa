# HƯỚNG DẪN LƯU BẰNG CHỨNG TIẾN ĐỘ (LEARNING PROGRESS EVIDENCE)

Thư mục này dùng để lưu ảnh chụp màn hình tab **"Progress"** trên edX sau khi bạn hoàn thành từng tuần/module:

### 1. Quy ước đặt tên file ảnh:
* `progress_module_01.png`: Ảnh chụp tiến độ sau khi xong Module 1.
* `progress_module_02.png`: Ảnh chụp tiến độ sau khi xong Module 2.
* ...
* `progress_final_completed.png`: Ảnh chụp tiến độ tổng kết (đạt 100% khóa học).

### 2. Tiêu chuẩn ảnh chụp để giảng viên công nhận:
* **Không chụp crop quá sát:** Hãy chụp rộng thấy rõ thanh URL trình duyệt (chứng minh đang ở trên trang web chính thức của edX).
* **Avatar & Tên tài khoản:** Góc trên cùng bên phải cần thấy rõ icon avatar hoặc tên tài khoản của bạn để chứng minh ảnh chính chủ, không phải lấy từ người khác.
